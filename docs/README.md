# BetterCLI for Claude documentation

The documentation is split into four kinds of page. Pick the one that matches what you need right now.

| You want to… | Read | |
|---|---|---|
| Learn the app by using it, start to finish | **[Tutorials](#tutorials)** | Lessons |
| Get one specific job done | **[How-to guides](#how-to-guides)** | Recipes |
| Look up an exact fact: a shortcut, a file, a flag | **[Reference](#reference)** | Dictionary |
| Understand why it works the way it does | **[Explanation](#explanation)** | Background |

Pages marked *(contributors)* are about the source code. Everything else is for people using the app.
