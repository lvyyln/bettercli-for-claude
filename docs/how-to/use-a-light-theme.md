# Use a light theme

BetterCLI's theme colours the app and the terminal. Claude Code also picks its own text colours, so you need to switch both.

1. Open the theme picker at the bottom of the sidebar and choose **Daylight**.
2. In any session, run:

   ```
   /theme
   ```

3. Choose one of Claude Code's light themes.

Claude Code saves its theme in your own Claude settings, so step 2 is needed only once, and it also applies when you run `claude` in a normal terminal.

To go back to dark, pick a dark theme in BetterCLI and run `/theme` again to choose a dark Claude theme.
